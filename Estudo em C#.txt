Qual é a função do método Main em um programa C#?
Servir como ponto de entrada onde o programa inicia sua execução.

int - armazena números inteiros (números inteiros), sem casas decimais, como 123 ou -123
double - armazena números de ponto flutuante, com casas decimais, como 19,99 ou -19,99
char - armazena caracteres individuais, como 'a' ou 'B'. Os valores char são delimitados por aspas simples
string - armazena texto, como "Olá Mundo". Os valores string são delimitados por aspas duplas

bool - armazena valores com dois estados: verdadeiro ou falso
